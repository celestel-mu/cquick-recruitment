## 任务 1：颜色目标检测
- **选择的目标颜色**：红色/橙色。
- **HSV 阈值上下界**：`lower = [0, 120, 70]`，`upper = [25, 255, 255]`。
- **最小轮廓面积**：500。
- **中心点计算方法**：使用 `cv2.boundingRect` 获取目标轮廓的外接矩形，取矩形中心点 `(x + w/2, y + h/2)` 作为 (u, v)。
- **多个候选目标选择规则**：利用 `max()` 函数按轮廓面积降序排列，直接选取面积最大的轮廓。
- **多图测试结果**：在红球和橙色篮球图中成功提取二值 Mask 并输出中心坐标。在纯白足球图中触发并输出了“未检测到目标”的异常提示。
- 三张原图来自网络公开图片。

## 任务 2：可视化与参数对比
- **标注**：已在原图中利用 `cv2.rectangle` 绘制外接框，`cv2.circle` 标出中心点，并打印了 `u=..., v=...` 坐标。
- **参数对比实验（双组对比）**：
  - **对比一（HSV 阈值饱和度 S）**：
    - 参数 A（S下限=120）：成功提取目标，但草地反光噪点较多。
    - 参数 B（S下限=220）：掩膜变干净，但目标高光边缘被过滤，导致框缩小或漏检。
  - **对比二（轮廓面积阈值）**：
    - 参数 A（面积>500）：成功框出篮球。
    - 参数 B（面积>50000）：目标被判定为噪点过滤，触发漏检。
- **坐标概念与失败分析**：像素坐标 (u, v) 仅代表目标在图像中的位置，不能直接当作机器人的真实世界坐标或运动指令。若需指导机器人，需依赖相机内外参进行转换。

## 问题与解决过程
1. **WSL2 死机**：最初尝试使用 WSL2 搭建 Linux 环境，但卡在 91.4% 且报 `0x8007019e` 错误。后听取建议，改用 VMware 安装完整的 Ubuntu 22.04，成功绕开系统底层坑，顺利配置了 ROS2 Humble。
2. **复制粘贴失效**：虚拟机中终端无法直接从 Windows 复制代码，通过 `sudo apt install open-vm-tools-desktop -y` 并重启，成功打通剪贴板。
3. **编译缺少工具**：运行 `colcon build` 时报错找不到命令，通过 `sudo apt install python3-colcon-common-extensions` 补齐后编译成功。
